# Robots

Учебный проект для изучения принципов объектно-ориентированного дизайна, паттерна MDI и разработки на Java.

## Как загрузить своего робота

1. **Создайте JAR-файл** с классами, реализующими интерфейсы:
   - `RobotBehavior` — логика движения (метод `calculate`)
   - `RobotView` — отрисовка (метод `draw`)

2. **Включите в JAR** необходимые DTO-классы: `RobotState`, `TargetState`, `Movement`, и 2 класса со своей реализацией поведения и отрисовкой самого робота, например класс с поведением танка `TankBehavior` и класс с отрисовкой `TankView`.

3. **Загрузите в приложение:**
   - Меню **Upload** → **Upload classes**
   - Выберите ваш JAR-файл

4. **Сброс к стандартному роботу:**
   - Меню **Upload** → **Reset robot**

## Требования

- Все классы должны быть в пакете `gui`
- Реализации должны иметь конструктор без параметров
